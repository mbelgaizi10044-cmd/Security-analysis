# 29LT Bukra

The platform's official font is 29LT Bukra (Bold for headlines, Regular for text). It is commercially licensed, so the font files are not published in this public repository.

If you hold a licence and the repository is private, add:

- `29LT-Bukra-Regular.otf`
- `29LT-Bukra-Bold.otf`

Until then the page uses IBM Plex Sans Arabic and Noto Kufi Arabic from Google Fonts.
